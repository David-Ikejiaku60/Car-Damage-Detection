# DentDetect 

**DentDetect** is a computer vision project that aims to classify images of cars as either damaged or undamaged.

## Project Objective

The goal of this project is to develop an image classification system that can analyze a car image and predict whether the vehicle shows visible damage.

This project is being developed as part of a hands-on learning task at GoMyCode, with the aim of gaining practical experience in machine learning, computer vision, and end-to-end application development.

## Planned Technologies

The following technologies are planned for the project:

* **Python:** Core programming language.
* **PyTorch and Torchvision:** Deep learning and image classification.
* **Pandas and NumPy:** Data handling and numerical operations.
* **Pillow:** Image processing.
* **Scikit-learn:** Dataset splitting and model evaluation.
* **FastAPI:** Backend API development.
* **SQLAlchemy:** Database interaction through an ORM.
* **PostgreSQL:** Database management, if selected for the final application.

The final technology stack may change as development progresses.

## Scope and Limitations

DentDetect is intended to identify visible vehicle damage from images. Predictions may be affected by image quality, lighting, viewing angle, and the types of damage represented in the training dataset.

The system is not intended to replace a professional vehicle inspection.
